# Сельская доставка

Веб-приложение (HTML/CSS/JS) + Supabase. Три роли: заказчик, курьер, админ.

## Запуск
Откройте `index.html` через любой статический хостинг (Vercel, Netlify, GitHub Pages).
Файлы: `index.html`, `style.css`, `app.js`.

## Что нужно сделать один раз
1. Supabase → Authentication → Sign In / Providers → Email: выключить **Confirm email**.
   Вход идёт по номеру телефона и паролю (номер превращается в служебную почту).
2. Сделать себя админом: зарегистрируйтесь в приложении как заказчик, затем в SQL Editor:
   `update public.profiles set role='admin' where phone = '<ваш номер как вводили при регистрации>';`
3. В приложении: Админ → Настройки → вписать реквизиты для оплаты дня курьерами.

## Оплата (версия 1)
Курьер переводит 100 ₽ вручную → жмёт «Я оплатил(а)» → админ подтверждает во вкладке «Оплаты» →
у курьера появляется одноразовый код → «Работать». Первые 7 календарных дней после регистрации бесплатны.
Повторное включение в тот же день не списывает оплату.
